Export & Download Diagram Presentasi UTS

Sistem Informasi POS Warung Klontong Haji Lubis. Semua diagram telah di-generate dengan format standar rekayasa perangkat lunak dan siap disematkan ke slide PowerPoint (PPT) maupun laporan UTS Anda.

💡 Kenapa sebelumnya tombol unduh di jendela chat tidak berfungsi?
Panel chat di IDE berjalan di dalam sandbox khusus yang membatasi browser untuk memicu pop-up unduh file OS otomatis.
Kabar baiknya: Halaman ini dibuka langsung di web browser Anda (Edge/Chrome), sehingga tombol "Unduh PNG" dan "Unduh SVG" di bawah ini 100% langsung menyimpan file ke folder Downloads Anda.

Mencakup scan kamera/webcam, validasi keranjang, pembayaran tunai, dan cetak struk.

2. Use Case Diagram: Pemisahan Hak Akses (RBAC)

Pemisahan fungsi Aktor Kasir (transaksi, cetak) vs Pemilik (laporan laba, stok, manajemen user).

3. Entity Relationship Diagram (ERD Konseptual)

Struktur relasi 7 entitas: Users, Products, Categories, Transactions, TransactionItems, StockLogs, AuditLogs.

🚀 2 Cara Praktis Memasukkan Diagram ke Slide PowerPoint:

  1. Cara 1: Gunakan File yang Sudah Ada di Komputer Anda (Paling Cepat & Hasil Terbaik)
    Ketiga file SVG diagram di atas sebenarnya sudah tersimpan langsung di folder proyek laptop Anda di:
    C:\latihan 2 prog\SOT_POS_Haji_Lubis
    Nama filenya: diagram_1_flowchart.svg, diagram_2_usecase.svg, dan diagram_3_erd.svg.
    👉 Cukup buka folder tersebut di File Explorer, lalu seret (drag & drop) file .svg langsung ke lembar slide PowerPoint Anda! Teks & garisnya akan 100% super tajam / tidak akan buram saat proyektor presentasi UTS.
  2. Cara 2: Klik Tombol "Unduh PNG (Resolusi Tinggi)" di Atas
    Jika PowerPoint Anda versi lama atau Anda lebih suka format gambar PNG, klik tombol biru "💾 Unduh PNG (Resolusi Tinggi)" pada masing-masing diagram di atas. Browser akan otomatis mengunduh file gambar PNG dengan resolusi 2x lipat (sangat tajam untuk PPT).
